# Capturing by hand

This adapter has no `capture` command: the runtime has no headless renderer.

1. Start the game with the asset placed in its test scene.
2. Take one still with the game's own screenshot key, framed so the whole asset and its base are in view.
3. Save it under the run's folder and record it as the step's evidence.

Done when the still shows the asset at its intended size against something of known size.
