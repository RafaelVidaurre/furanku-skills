# Build a representative hero-shot set

Choosing a visual direction starts coverage work; one winning comparison image does not finish art direction. A complete current style library contains **at least three distinct, human-approved hero shots** that work together as a visual target for this game. Three is a floor, not a default stopping point or a requirement to invent three environments. Use agent and human judgment to add shots wherever important visual questions remain.

“Hero shot” names a preserved visual target, not a cinematic camera instruction. Coverage normally uses the player's gameplay view under the [gameplay-frame specification](style-images.md#translate-the-brief-into-visible-instructions). An approved supporting close-up can establish materials or construction detail, but cannot substitute for missing gameplay-scale evidence.

## Guide the coverage

1. Reuse the game brief, supplied references and selected direction. Identify what the current shots establish and the consequential situations they leave untested. Consider the game's expected range of places, activities, visual states, subjects, scale and readability, only where relevant. Derive coverage from this game rather than a fixed genre checklist; ask about unknown expectations instead of inventing content to fill slots.
2. Propose a small set of complementary shots. For each, state the situation to show and the visual question it answers; explain why it adds useful coverage. Discuss the highest-impact gap with the human and adjust the set. A game in one location may need different meaningful activities or states there; a game spanning many settings may need more than three shots. Near-duplicates, crops or palette swaps do not satisfy the minimum.
3. Keep the selected art direction coherent across the set: common shape language, materials/shading and other agreed rules, with only approved variations. This is different from the initial 2–4 competing directions. Reuse suitable approved shots; generate only the missing or revised coverage. Carry forward still-approved shots from earlier revisions when appropriate: the minimum applies to the current set, not the number of new files in each revision.
4. For each batch, state its coverage purposes, shared direction, image count and remaining gaps. Apply [task intent](task-intent.md): execute an already requested, understood batch without reconfirmation; otherwise use the [summary and start choice](interaction.md#confirm-a-style-round). Choosing a direction or identifying gaps alone does not authorize more images. Apply [style-image execution](style-images.md) too: fresh sessions for independent images, with approved shared targets deliberately attached where supported; use edits for deliberate modifications. Do not pass rejected alternative styles or sibling conversation history.
5. Show the actual images together and guide review of both consistency and coverage. Point out missing or contradictory evidence; recommend the next useful shot or question instead of stopping at a count. Ask whether the set captures the intended visual range or needs changes. Record the human's approval of the specific current set and its coverage, with any bounded unresolved details. If material gaps remain, the style library is still in progress even with three images.

## Save progress without claiming completion

Preserve individually approved shots through [hero-shot preservation](style-exploration.md#carry-the-decision-forward), even while the set is incomplete. In the canonical guide, give each shot its coverage role and keep a compact list of approved shots, planned gaps and deliberately out-of-scope situations. User references inform the brief; they are not automatically approved hero shots. Save the approved scope honestly rather than claiming the rest of an image was accepted.

**Coverage complete:** at least three distinct approved shots in the current gallery, coherent with the chosen direction, and the human agrees they cover the game's important visual situations. This is a visual judgment supported by the gallery, not an automatic image-count test. If generation is unavailable, budget is exhausted or the human pauses early, save progress and name the gap; do not generate without authorization or mark the library complete. An older single-shot library resumes at this coverage step without discarding its approved direction. Only a completed, preserved set reaches routine [exploration cleanup](style-cleanup.md).
