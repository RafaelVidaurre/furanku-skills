# Native histories to audited domain observations

## What this establishes

Native evidence can now pass through task extraction, automatic packet preparation,
requirement applicability, domain assessment, structural validation, private caching
and independent source review. No task requirements were manually rewritten before
the three new scoring calls. GPT-6 Sol medium performed extraction and assessment;
the root agent audited judgments against the original evidence.

This is a small, deliberately bounded text pilot. It establishes useful observations,
not calibrated model rankings, full-history coverage or best-value routing. The
installed skill, selector and production capability tables were not changed.

## Rubric and audit

The [procedure](../../skills/model-routing/references/domain-assessment.md) supplies
all [21 domain definitions](../../skills/model-routing/references/retrospective-domains.json).
Scores are provisional ordinal observations: 0 unusable, 1 major correction needed,
2 usable with a minor remaining defect, 3 meets the requested criteria, 4 evidenced
quality beyond those criteria. Missing evidence stays unscored; absent domains
are not zero. Workflow compliance and inapplicable conditions do not add quality
points. Recovered mistakes and external blockers are recorded separately.

For C, the frozen reference expected a satisfactory report correction. Sol found
an additional arithmetic inconsistency: the displayed numbers sum to 0.501, while
an explicitly reasserted sentence says 0.502. Source review confirmed it. The
unrounded underlying result remains unknown. The frozen reference was retained,
not rewritten to turn this discovery into an apparent agreement.

The audit also corrected Sol:

- The requested evidence-availability correction was fulfilled; the separate
  arithmetic defect does not make that particular requirement unmet.
- A research score was excluded: the investigation was incidental to the
  documentation deliverable.
- The numeric finding needed the original table source as well as the diff;
  the diff alone omitted the numeric rows.

Documentation and quantitative scores concern the same defect in one task.
They are correlated observations, not two independent model trials. The report
integration has direct command-linked fast-forward, push and remote-state evidence.
Raw evaluator outputs, separately reviewed results and source hashes stay private.

## Reuse and implementation

`domain_assess.py` mechanically copies original sources and adds the full taxonomy;
it rejects mixed, unknown, inherited and summary-only actor attribution. Assessors
judge purposes and outcomes. `assessment_store.py` validates structure and reuses
completed unchanged tasks. It now detects overlapping or unknown task boundaries
under different IDs and returns `needs_scope_review`, preventing a second scoring
call. New jobs carry native request anchors so genuinely disjoint tasks can proceed.

The private ledger records raw results as semantically unreviewed. A separate audit
approves or corrects observations; storage completion never approves routing changes.
Source E correctly completes extraction without completing an assessment. Source D
demonstrates reuse across legacy task naming rather than receiving another score.

Historical assignment bodies mention worker models, despite withholding the actor
map. This was not fully blinded. B and C required one and two structural output
revisions respectively; those initial outputs were retained. These assessor output
repairs are separate from mistakes made by the historical worker.

## Remaining work

The end-to-end path needs a representative larger batch, including substantive
worker failures, richer noncoding work and verified Grok identities. Multimodel
contribution splitting and unreadable assignment recovery remain coverage limits.
Visual and auditory quality need actual artifacts. Before capability tables change,
calibrate score agreement, account for task difficulty, collect cost observations,
and estimate uncertainty from independent sessions with bounded outlier influence.
The retrospective epic remains open.
